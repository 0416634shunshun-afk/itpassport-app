# 新卒研修 発表資料作成プロンプト集

新卒研修として Claude を活用してツールを開発し、その**開発プロセスをメイン**に発表するための
プロンプト集。**開発を行ったCoworkのチャットに、そのまま順番に貼り付けて送信すればよい形式**になっている。
同じチャット内で使う前提のため、途中の出力をコピー&ペーストし直す必要はない(Claudeが自分で
それまでの会話履歴を参照する)。

## 使い方

開発が一区切りついたら、同じチャットで以下のプロンプトを**上から順に1つずつ**送信する。

---

### STEP1: 開発の経緯を整理する

```
このチャットのやり取りをすべて振り返って、開発の経緯を時系列で整理してください。
①最初にどんな課題・要件からスタートしたか
②どんな設計・実装方針で進めたか(変更した方針があれば理由も)
③実装の流れ(何をどの順番で作ったか)
④詰まった点・エラーが出た点と、どう解決したか
⑤最終的にできあがったもの
`dev-summary.md` として出力してください。
```

### STEP2(任意): 抜け漏れの確認

```
上記の整理で抜けていそうな点はありますか?
特に「試行錯誤した箇所」「途中で方針転換した箇所」「意外とスムーズにいった箇所」を
見落としていないか、チャット履歴を見直して確認してください。
```

### STEP3: Claude活用の振り返り(良い例・悪い例)

```
このチャットのやり取りの中から、良い指示の出し方ができた例と、曖昧で手戻りが発生した例を
それぞれ2〜3個、実際のプロンプトを引用しながら挙げてください。
Before(最初のプロンプト)→気づき→After(改善したプロンプト)の形式で整理してください。
```

### STEP4: Claude活用の振り返り(任せた部分・自分で判断した部分)

```
このチャットの中でClaudeに任せた部分と、自分で判断・修正した部分を整理してください。
AIに任せてよかった作業、逆に人間が確認・修正すべきだった作業を分けてください。
```

### STEP5: 発表構成案を作る

```
ここまで整理した開発の経緯とAI活用の振り返りをもとに、
新卒研修の発表資料(開発プロセスをメインに、10分程度)の構成案を作ってください。

想定する流れ:
①テーマ・課題設定
②設計方針
③実装の流れ(時系列)
④つまずきと解決
⑤Claude活用の工夫
⑥今後の展望・学び

各スライドのタイトルと要点を3行程度でまとめてください。
```

### STEP6: スライドを生成する

```
上記の構成案をもとに、パワーポイントのスライドを作成してください。
1スライドあたり情報を詰め込みすぎず、コードの前後比較やスクリーンショットを
入れる箇所は「[ここに画像]」のように示してください。
```

---

## 運用のコツ

- 各STEPは同じチャットで順番に送るだけでよい。前のSTEPの出力をコピペし直す必要はない
- STEP2は任意。時間がなければ省略してSTEP3に進んでも問題ない
- 開発が複数セッション(複数のチャット)にまたがった場合は、セッションごとにSTEP1を実行し、
  出力された`dev-summary.md`の内容をつなぎ合わせてからSTEP5に進む
- STEP1の出力は下書きなので、自分の記憶と照らし合わせて事実と違う点がないか確認してからSTEP5に進む
