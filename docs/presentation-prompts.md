# 新卒研修 発表資料作成プロンプト集

新卒研修として Claude を活用してツールを開発し、その**開発プロセスをメイン**に発表するための
プロンプト集。開発が一区切りついた後、**そのセッションのチャット履歴を振り返らせて**発表資料の
もとになる情報を引き出す流れになっている。

## 使い方

1. 開発が終わったら「1. チャット履歴から開発内容を振り返るプロンプト」を実行し、開発の経緯を整理・書き出す
2. 続けて「2. Claude活用の振り返りプロンプト」でAI活用の学びを言語化する
3. それらをもとに「3. 発表構成を考えるプロンプト」で構成案を作る
4. 最後に「4. スライド生成プロンプト」で実際のスライドに落とし込む

開発中に別途ログを取る必要はなく、**開発に使ったチャット自体をそのまま資料化の起点にする**のがポイント。

---

## 1. チャット履歴から開発内容を振り返るプロンプト

開発が一区切りついたタイミングで、同じチャット(セッション)内で実行する。過去のやり取りをClaude自身に読み返させ、経緯を整理させる。

```
このチャットのやり取りをすべて振り返って、開発の経緯を時系列で整理してください。
以下の観点でまとめてください。
①最初にどんな課題・要件からスタートしたか
②どんな設計・実装方針で進めたか(変更した方針があれば理由も)
③実装の流れ(何をどの順番で作ったか)
④詰まった点・エラーが出た点と、どう解決したか
⑤最終的にできあがったもの

`dev-summary.md` として出力してください。
```

### 抜け漏れを防ぐ補助プロンプト

```
上記の整理で抜けていそうな点はありますか?
特に「試行錯誤した箇所」「途中で方針転換した箇所」「意外とスムーズにいった箇所」を
見落としていないか、チャット履歴を見直して確認してください。
```

---

## 2. Claude活用の振り返りプロンプト

新卒研修の発表では、成果物そのものより「AIをどう使ったか」が評価されやすい。チャット履歴を実際に見返せるので、具体的な引用も交えて振り返らせる。

```
このチャットのやり取りの中から、良い指示の出し方ができた例と、曖昧で手戻りが発生した例を
それぞれ2〜3個、実際のプロンプトを引用しながら挙げてください。
Before(最初のプロンプト)→気づき→After(改善したプロンプト)の形式で整理してください。
```

```
このチャットの中でClaudeに任せた部分と、自分で判断・修正した部分を整理してください。
AIに任せてよかった作業、逆に人間が確認・修正すべきだった作業を分けてください。
```

---

## 3. 発表構成を考えるプロンプト

「1.」「2.」で出力した内容をもとに、構成案を作らせる。

```
以下は、このチャットから振り返って整理した開発の経緯とAI活用の振り返りです。
新卒研修の発表資料(開発プロセスをメインに、10分程度)の構成案を作ってください。

想定する流れ:
①テーマ・課題設定
②設計方針
③実装の流れ(時系列)
④つまずきと解決
⑤Claude活用の工夫
⑥今後の展望・学び

各スライドのタイトルと要点を3行程度でまとめてください。

[ここに dev-summary.md の内容を貼り付け]
```

---

## 4. スライド生成プロンプト

構成案が固まったら、実際のパワーポイントを生成させる。

```
上記の構成案をもとに、パワーポイントのスライドを作成してください。
1スライドあたり情報を詰め込みすぎず、コードの前後比較やスクリーンショットを
入れる箇所は「[ここに画像]」のように示してください。
```

---

## 運用のコツ

- 開発中に別ファイルで記録を取らなくても、**チャット履歴自体が発表の一次資料**になる。ただし長い開発で複数セッションに分かれた場合は、セッションごとに「1.」を実行して`dev-summary.md`に追記していくとよい
- 「1.」の出力はあくまで下書きなので、自分の記憶と照らし合わせて事実と違う点がないか確認してから発表構成に進む
- コミットメッセージやPR説明も、チャット履歴と合わせて振り返りの裏付け資料として使える
